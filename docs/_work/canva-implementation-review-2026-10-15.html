ตรวจ Canva 12 สไลด์เทียบกับโค้ด วันที่ 15 ตุลาคม 2569

สรุปง่าย ๆ: สไลด์ต้องแก้ตรงไหน?

ระบบหลักทำงานได้แล้ว แต่สไลด์ยังมีข้อมูลเก่า และบางภาพเป็นสิ่งที่ออกแบบไว้แต่ยังทำไม่เสร็จ

ทำได้แล้ว: จดมิเตอร์ คำนวณค่าใช้จ่าย สร้างและอนุมัติบิล รับเงินสด ออกและพิมพ์ใบเสร็จ รวมถึงแยกสิทธิ์ Admin / Staff และบันทึกการเปลี่ยนแปลงสำคัญ

6 จุดที่ควรแก้ก่อนนำเสนอ

  1. เปลี่ยน MySQL เป็น Supabase (PostgreSQL)

    แก้ทั้งรูปฐานข้อมูลหน้า 6 และชื่อฐานข้อมูลหน้า 10 ให้ตรงกัน

  2. นำ Chart.js และ Aiven ออกจากรายการที่ใช้อยู่

    ยังไม่มี Chart.js ในแอป ส่วนฐานข้อมูลปัจจุบันใช้ Supabase ภาพกราฟหน้า 7 จึงควรระบุว่าเป็น “แบบจำลอง”

  3. LINE ยังไม่ส่งข้อความจริง

    ผูกบัญชีและเตรียมคิวแจ้งเตือนได้แล้ว แต่ยังต้องทำส่วนส่งบิลและยืนยันชำระเงิน ภาพข้อความหน้า 9 เป็นตัวอย่างที่ออกแบบไว้

  4. แก้ภาพหน้า Staff ให้ตรงสิทธิ์

    Staff ดูห้องและจดมิเตอร์ได้ แต่อนุมัติบิลหรือรับเงินไม่ได้ ภาพหน้า 8 ไม่ควรมีปุ่มงาน Admin ปะปน

  5. แยก GitHub ออกจากบริการ Deploy

    แก้ “GitHup” เป็น “GitHub” ใช้จัดการซอร์สโค้ด ส่วน Render และ cron-job.org ให้ระบุว่าเป็นแผนหรือรอยืนยันการใช้งานจริง

  6. แยก “เป้าหมาย” ออกจาก “ทำเสร็จแล้ว”

    เพิ่ม/แก้ข้อมูลห้อง ผู้เช่า และอัตราบริการยังทำไม่ครบ เช่นเดียวกับ Dashboard แบบกราฟ จึงไม่ควรนำเสนอว่าทุกอย่างในขอบเขตเสร็จแล้ว

พูดประกอบสไลด์แบบนี้ได้เลย

ต้นแบบทำงานตั้งแต่จดมิเตอร์ คำนวณบิล รับเงินสด ไปจนถึงออกใบเสร็จได้แล้ว โดยใช้ Node.js, Express, EJS และฐานข้อมูล PostgreSQL บน Supabase ส่วน Dashboard ตามภาพและการส่งแจ้งเตือน LINE จริงยังอยู่ระหว่างพัฒนา
อีก 1 เรื่องในโค้ดที่ควรแก้: GitHub Actions

ไฟล์ CI ยังตั้งค่า MySQL อยู่ ต้องเปลี่ยนให้ใช้ PostgreSQL และตั้งค่าฐานข้อมูลทดสอบให้ตรงกับระบบปัจจุบันก่อนอ้างว่า CI ทดสอบครบแล้ว ครั้งนี้ตรวจจากไฟล์ ไม่ได้รัน workflow ออนไลน์

ดูรายงานละเอียด พร้อมตารางเทียบครบ 12 สไลด์และหลักฐานจากโค้ด
