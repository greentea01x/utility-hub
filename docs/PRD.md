## ภาษาอังกฤษ

# 1. แนวคิดของโครงงาน

โครงงานนี้เป็น Web Application สำหรับช่วยเจ้าของอพาร์ตเมนต์ หอพัก หรือนิติบุคคลในการจัดการค่าใช้จ่ายของแต่ละห้อง โดยระบบจะเน้น 3 ค่าใช้จ่ายหลัก ได้แก่

- ค่าน้ำ
- ค่าไฟ
- ค่าส่วนกลาง

ระบบจะไม่คิดค่าเช่าห้อง

เจ้าหน้าที่สามารถกรอกเลขมิเตอร์น้ำและไฟของแต่ละห้องผ่านเว็บไซต์ ระบบจะคำนวณจำนวนหน่วยที่ใช้และยอดเงินให้อัตโนมัติ

สำหรับค่าส่วนกลาง ระบบจะคำนวณจากขนาดพื้นที่ของห้อง เช่น

**ค่าส่วนกลาง = ขนาดห้อง × อัตราค่าส่วนกลางต่อตารางเมตร**

เมื่อระบบคำนวณค่าใช้จ่ายเสร็จแล้ว จะสร้างบิลให้นิติบุคคลตรวจสอบและอนุมัติ หลังจากนั้นระบบสามารถส่งรายละเอียดบิลและแจ้งเตือนผู้เช่าผ่าน LINE Official Account

เมื่อผู้เช่านำเงินสดมาชำระที่สำนักงาน เจ้าหน้าที่สามารถบันทึกการรับเงินในระบบ ออกใบเสร็จ และส่งข้อความยืนยันการชำระผ่าน LINE OA ได้

# 2. ปัญหาที่โครงงานต้องการแก้ไข

การจัดการค่าน้ำ ค่าไฟ และค่าส่วนกลางของอพาร์ตเมนต์ในบางแห่งยังใช้การจดลงกระดาษหรือ Excel ซึ่งอาจเกิดปัญหา เช่น

- กรอกเลขมิเตอร์ผิด
- คำนวณค่าใช้จ่ายผิด
- ค้นหาประวัติย้อนหลังยาก
- ไม่ทราบว่าห้องใดจ่ายแล้วหรือยัง
- การแจ้งยอดผู้เช่าต้องทำด้วยตนเอง
- การติดตามยอดค้างชำระใช้เวลามาก
- ข้อมูลกระจัดกระจาย
- ตรวจสอบการใช้น้ำและไฟย้อนหลังได้ยาก

ระบบนี้จะช่วยรวมข้อมูลทั้งหมดไว้ในที่เดียวและลดขั้นตอนการทำงานของเจ้าหน้าที่

# 3. วัตถุประสงค์ของโครงงาน

1. พัฒนา Web Application สำหรับจัดการข้อมูลห้องและผู้เช่า
2. จัดเก็บเลขมิเตอร์น้ำและไฟของแต่ละห้อง
3. คำนวณค่าน้ำและค่าไฟโดยอัตโนมัติ
4. คำนวณค่าส่วนกลางตามขนาดพื้นที่ของห้อง
5. สร้างบิลค่าใช้จ่ายรายเดือน
6. บันทึกและตรวจสอบสถานะการชำระเงิน
7. ออกใบเสร็จรับเงิน
8. ส่งบิลและการแจ้งเตือนผ่าน LINE Official Account
9. แสดงรายงานและ Dashboard สำหรับเจ้าหน้าที่
10. สามารถตรวจสอบประวัติการใช้น้ำ ไฟ และการชำระเงินย้อนหลังได้

# 6. การคำนวณค่าน้ำ

เจ้าหน้าที่กรอกเลขมิเตอร์

ตัวอย่าง

เลขเดือนก่อน = 1,250

เลขเดือนนี้ = 1,260

ดังนั้น

จำนวนหน่วยที่ใช้

**1,260 - 1,250 = 10 หน่วย**

หากอัตราค่าน้ำคือ

18 บาท / หน่วย

ระบบคำนวณ

**10 × 18 = 180 บาท**

ดังนั้น

ค่าน้ำ = **180 บาท**

---

# 7. การคำนวณค่าไฟ

**5,350 - 5,280 = 70 หน่วย**

หากอัตราค่าไฟคือ

8 บาท / หน่วย

**70 × 8 = 560 บาท**

ดังนั้น

ค่าไฟ = **560 บาท**

# 8. การคำนวณค่าส่วนกลาง

ระบบจะคิดค่าส่วนกลางตามพื้นที่ของห้อง

สูตร

**ขนาดห้อง × อัตราค่าส่วนกลางต่อตารางเมตร**

ตัวอย่าง

ห้อง 205 มีขนาด

30 ตารางเมตร

กำหนดค่าส่วนกลาง

35 บาท / ตารางเมตร

ดังนั้น

**30 × 35 = 1,050 บาท**

ค่าส่วนกลางของห้อง 205 เท่ากับ

**1,050 บาท**

# 20. สถานะของบิล

แนะนำให้มีประมาณ 4 สถานะ

**Draft**

บิลสร้างแล้วแต่ยังไม่ได้ตรวจสอบ

↓

**Unpaid**

ตรวจสอบแล้วและส่งให้ผู้เช่าแล้ว

↓

**Paid**

ผู้เช่าชำระเรียบร้อย

หรือ

**Overdue**

เลยวันครบกำหนดแล้วยังไม่ชำระ

ดังนั้น Flow คือ

**Draft → Unpaid → Paid**

หรือ

**Draft → Unpaid → Overdue → Paid**

# 29. คำอธิบายโครงงานสำหรับพูดกับอาจารย์

"โครงงานของเราคือการพัฒนา Web Application สำหรับจัดการค่าสาธารณูปโภคและค่าส่วนกลางของอพาร์ตเมนต์ โดยระบบจะไม่มีการคิดค่าเช่าห้อง

เจ้าหน้าที่จะกรอกเลขมิเตอร์น้ำและไฟของแต่ละห้องผ่านเว็บไซต์ ระบบจะนำเลขมิเตอร์ปัจจุบันมาหักกับเดือนก่อนเพื่อหาจำนวนหน่วยที่ใช้ และคำนวณค่าน้ำกับค่าไฟให้อัตโนมัติ

ส่วนค่าส่วนกลางจะคำนวณตามขนาดพื้นที่ของแต่ละห้อง เช่น จำนวนตารางเมตรคูณกับอัตราค่าส่วนกลางต่อตารางเมตร

หลังจากนั้นระบบจะรวมค่าน้ำ ค่าไฟ และค่าส่วนกลางเพื่อสร้างบิลรายเดือน ให้นิติบุคคลตรวจสอบและอนุมัติ ก่อนส่งรายละเอียดให้ผู้เช่าผ่าน LINE Official Account

เมื่อผู้เช่านำเงินสดมาชำระที่สำนักงาน เจ้าหน้าที่จะยืนยันการรับเงินผ่านระบบ ระบบจะเปลี่ยนสถานะบิล ออกใบเสร็จ และส่งข้อความยืนยันการชำระผ่าน LINE OA

นอกจากนี้ยังมี Dashboard รายงานยอดชำระ ยอดค้างชำระ รวมถึงประวัติการใช้น้ำและไฟย้อนหลังของแต่ละห้อง"
