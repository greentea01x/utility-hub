# Utility Hub

ระบบเว็บสำหรับจัดการค่าน้ำ ค่าไฟฟ้า และค่าส่วนกลางของอพาร์ตเมนต์ ตั้งแต่จดมิเตอร์ คำนวณบิล รับชำระเงินสด ไปจนถึงออกใบเสร็จ

## ความสามารถหลัก

- ดูข้อมูลห้องพักและผู้พักอาศัย
- บันทึกเลขมิเตอร์น้ำและไฟฟ้า พร้อมชื่อช่างผู้จดมิเตอร์
- คำนวณค่าสาธารณูปโภคและค่าส่วนกลางตามพื้นที่ห้อง
- สร้างและอนุมัติบิลรายเดือน บันทึกการรับเงินสด และออกใบเสร็จ
- ดูข้อมูลสรุป กราฟการใช้น้ำและไฟฟ้า และรายงานลูกหนี้ค้างชำระ
- บันทึกประกาศและแยกสิทธิ์การใช้งานระหว่างผู้ดูแลระบบกับเจ้าหน้าที่

การส่งข้อความผ่าน LINE Official Account ยังอยู่ระหว่างพัฒนา

## เทคโนโลยี

Node.js 24, Express 5, EJS, HTML/CSS, JavaScript และ Supabase (PostgreSQL)

## เริ่มใช้งาน

1. ติดตั้ง Node.js 24 และสร้างฐานข้อมูลบน Supabase
2. ติดตั้งแพ็กเกจและเตรียมไฟล์ตั้งค่า

   ```bash
   npm ci
   cp .env.example .env
   ```

3. กำหนดค่าใน `.env`

   - `DATABASE_URL`: ที่อยู่เชื่อมต่อ PostgreSQL จาก Supabase โดยเลือก **Session Pooler** และใช้ `sslmode=require`
   - `SESSION_SECRET`: ค่าสุ่มสำหรับป้องกันเซสชัน
   - `SEED_ADMIN_PASSWORD`: รหัสผ่านเริ่มต้นของผู้ดูแลระบบ

4. สร้างข้อมูลตัวอย่างและเปิดเว็บ

   **คำเตือน:** `db:reset` จะลบตารางเดิมและสร้างข้อมูลตัวอย่างใหม่ ใช้กับฐานข้อมูลสำหรับพัฒนาหรือสาธิตเท่านั้น

   ```bash
   npm run db:reset
   npm run dev
   ```

5. เปิด [http://localhost:3000/login](http://localhost:3000/login) เข้าสู่ระบบด้วยชื่อ `admin` และรหัสผ่านจาก `SEED_ADMIN_PASSWORD`

หากมีฐานข้อมูลเดิมอยู่แล้ว ให้ใช้ `npm run db:upgrade` เพื่อปรับโครงสร้างโดยเก็บข้อมูลเดิมไว้ แทนการรัน `db:reset`

## การทดสอบ

```bash
npm test
npm run test:e2e:isolated
```

การทดสอบที่ใช้ฐานข้อมูลต้องกำหนด `TEST_DATABASE_URL` ใน `.env.test` โดยชุดทดสอบจะใช้สคีมาชั่วคราวเพื่อแยกจากข้อมูลหลัก

ดูรายละเอียดใน [การทดสอบฐานข้อมูล](test/integration/README.md) และ [การทดสอบผ่านเบราว์เซอร์](test/e2e/README.md)

## ต้นแบบสำหรับผู้พักอาศัย

เปิด `/resident-preview/` เพื่อดูต้นแบบเมนูบิล ประวัติชำระเงิน ใบเสร็จ ข้อมูลห้อง ประกาศ และติดต่อสำนักงาน โดยใช้ข้อมูลสมมุติและยังไม่เชื่อมต่อฐานข้อมูลหรือ LINE
