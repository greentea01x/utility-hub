# เว็บต้นแบบสำหรับผู้พักอาศัย

บันทึกการเลือกแบบวันที่ **16 ตุลาคม 2026 (Asia/Bangkok)**: ผู้ใช้เลือกแนวทางเมนูคอนโดสีเขียว พร้อมการ์ดสีพาสเทลและอิโมจิ 6 เมนู และขอให้สร้างหน้าเว็บปลายทางเพื่อเก็บไว้ใช้พัฒนาต่อจากงานภายในสำนักงานของภาคเรียนนี้

สถานะ: **เลือกเป็นแนวทางสำหรับพัฒนาต่อไป** เป็นเว็บต้นแบบสำหรับทดลองหน้าจอและการใช้งาน ยังไม่ใช่ฟีเจอร์ที่เปิดใช้จริง

แบบอ้างอิง: [ภาพแชทและเมนูที่ผู้ใช้เลือก](../../docs/mockups/line-chat/05-condo-rich-menu-redesign.png) · [บันทึกการตัดสินใจแบบ JSON](design-decision.json)

## หน้าที่เก็บไว้ใช้

หน้าแรกคือ `index.html` และใช้ชื่อ **ศุภาลัย เรสซิเดนซ์** ตามภาพที่ผู้ใช้เลือก

| เมนู | ไฟล์ | สิ่งที่ผู้พักอาศัยพบเมื่อกด |
| --- | --- | --- |
| 💰 บิลประจำเดือน | `bills.html` | รายการค่าน้ำ ค่าไฟ ค่าส่วนกลาง ยอดรวม วันครบกำหนด และคำแนะนำชำระเงินสดที่สำนักงาน |
| 🗓️ ประวัติการชำระ | `history.html` | รายการย้อนหลัง ตัวกรอง และดาวน์โหลดข้อมูลตัวอย่างเป็น CSV |
| 🧾 ใบเสร็จรับเงิน | `receipts.html` | เลือกดูใบเสร็จย้อนหลังและสั่งพิมพ์ |
| 🏢 ข้อมูลห้องพัก | `room.html` | ข้อมูลห้อง 205 ที่ผูกบัญชีไว้ในตัวอย่าง แสดงแบบอ่านอย่างเดียว |
| 📣 ข่าวสารและประกาศ | `announcements.html` | กรองประกาศและเปิดอ่านรายละเอียด |
| 🎧 ติดต่อสำนักงาน | `contact.html` | เวลาทำการและแบบฟอร์มตัวอย่างที่บันทึกไว้เฉพาะในเบราว์เซอร์เครื่องนี้ |

ข้อมูลทั้งหมดเป็นข้อมูลจำลอง: บิลเดือนกันยายน 2026 ของห้อง 205 ยอด **1,790 บาท** ยังไม่ชำระ และมีรายการชำระแล้วในเดือนก่อนหน้า แบบฟอร์มติดต่อไม่ได้ส่งข้อความถึงเจ้าหน้าที่

## เปิดดูต้นแบบ

ใช้ระบบ Express เดิมที่ตั้งค่าไว้แล้ว:

```sh
npm run dev
```

เปิด `/resident-preview/` บนพอร์ตที่ระบบแสดง หรือดูเฉพาะต้นแบบโดยไม่ต้องเปิดระบบหลังบ้าน:

```sh
python3 -m http.server 4174 --bind 127.0.0.1 --directory public
```

จากนั้นเปิด <http://127.0.0.1:4174/resident-preview/> ไม่ต้องติดตั้งแพ็กเกจเพิ่ม และต้นแบบไม่ต้องเรียกบริการภายนอก

## ขอบเขตเมื่อพัฒนาจริง

งานนี้เก็บหน้าเว็บและรูปแบบที่เลือกไว้ โดยไม่เปลี่ยนฐานข้อมูลหรือระบบเจ้าหน้าที่ และยังไม่เชื่อม LINE, LIFF, API, ระบบยืนยันตัวตน หรือการชำระเงินออนไลน์

เมื่อเชื่อมใช้งานจริง ต้องตรวจสอบตัวตนจาก LINE/LIFF ที่ฝั่งเซิร์ฟเวอร์ และตรวจสิทธิ์ผู้พักอาศัยกับห้องในทุกคำขอข้อมูลบิล ประวัติ และใบเสร็จ ห้ามใช้เลขห้องจากหน้าเว็บเป็นหลักฐานสิทธิ์เพียงอย่างเดียว ส่วน API สำหรับอ่านข้อมูลผู้พักอาศัยและรับเรื่องติดต่อยังต้องพัฒนาเพิ่มเติม

การสร้างต้นแบบนี้ไม่ถือเป็นการยืนยันว่าทดสอบระบบจริงหรือเชื่อมต่อบริการสำเร็จแล้ว
